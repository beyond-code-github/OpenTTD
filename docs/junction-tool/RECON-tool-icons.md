## 3. How GUI sprites are added here
- Base-set extra graphics = media/baseset/openttd/*.nfo + sprites/*.png, compiled to media/baseset/openttd.grf (676 KB, COMMITTED, with openttd.grf.hash 'b198439b...'). media/baseset/openttd/CMakeLists.txt: if grfcodec+nforenum are found (cmake/FindGrfcodec.cmake) it regenerates via `create_grf_command` (lists every nfo/png); otherwise the committed .grf is used. This machine has neither tool on PATH (`which grfcodec nforenum` empty), so a rebuild of the grf is not possible here as is; the committed binary must be regenerated elsewhere/installed tools.
- Index: openttdgui.nfo starts with `05 15 \b 192 // OPENTTD_SPRITE_COUNT` (Action 5, count 192); sprites are listed in order, ids = SPR_OPENTTD_BASE (4896) + position. src/table/sprites.h has `OPENTTD_SPRITE_COUNT = 192` (:61) and SPR_SIGNALS_BASE = BASE + COUNT (:192), so every later base-set block shifts automatically: the count must match in BOTH places.
- Recent precedent (convert_road / build_tram / group_livery): one extra PNG each (openttdgui_convert_road.png etc.) + nfo lines `-1 sprites/<png> 8bpp x y w h xrel yrel normal`; button sprite 20x20; cursor sprite 32x32 (same png, x offset 24). Format is 8bpp only (0 lines with 32bpp), single 'normal' zoom (the engine scales for other zooms). New sprites go at the END of the openttdgui.nfo list (existing ids unchanged); these two tools' other sprites need `static const SpriteID` lines in sprites.h and bump of OPENTTD_SPRITE_COUNT.
- Also: nfo `grf` header text lists credits; openttd.grf.hash is updated by the build.
- Steps (one icon set): (1) draw 20x20 + 32x32 cursor in palette-indexed 8bpp PNG (OpenTTD DOS palette) in media/baseset/openttd/; (2) append nfo lines to openttdgui.nfo and add the PNG to the CMake PNG_SOURCE_FILES list; (3) bump count in nfo (\b 192 -> n) and OPENTTD_SPRITE_COUNT; (4) add SPR_ constants; (5) regenerate openttd.grf with grfcodec/nforenum (install them) and commit grf + hash; (6) use in rail_gui.cpp / junction windows (WWT_PUSHIMGBTN + SetSpriteTip). Roughly 1 hour of code once art exists; art in an 8bpp palette is the real cost. Loading note: the game must find the rebuilt openttd.grf (build copies it; test client needs a rebuild of the baseset).
