## Questions (docs/junction-tool/CARDS-crossings.md, read it whole)
For 3-way hubs where the branch has two or more tracks each way (coop BBHs: LL_RR x LL_RR or wider; wiki "Ultimate 3-way" 2/4 tracks, "Compact 3-Way Branch-Merge"), from the largest, clearest images:
1. C1: where two TURNING legs cross (e.g. main->branch exits from opposite sides, or two branch->main joins), which one is on the bridge (or in the tunnel)? Is there a consistent pattern (the leg from the far side of the main line over? the outer one over? whichever is shorter?).
2. C2: where a track still carrying both through and turning traffic (before its exit split) crosses a turning leg, which is on the bridge?
3. C3: where two branch joiners cross, which is over, and is it the one whose merge into the main line is farther from or nearer to the main line, or something else?
4. D224 check: do the designs merge two branch legs bound for the same main lane before joining it (one joiner per lane), or join twice?
5. D223 check: at main x main crossings, is the through lane over and the turn under?
For each answer: the image file name(s), what you see (describe the crossing), and how sure you are (image size/clarity). Mark "not visible" where an image is too small (many are 75x75 icons or 140 px thumbnails).
