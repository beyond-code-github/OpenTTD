# D449 P2: S-bends from v1's slot solve (BuildPlanarSlots), HiGHS stage A on the locked set, vs CP-SAT's free optimum (brief BRIEF-d449-p2)

Probe: `[slotsstep2]` with `PLANAR_D449_SLOTS=1` (T3 added to the hub loop, only with that knob or `PLANAR_SLOTS_HUB=T3`). Inputs rebuilt from the variant's tag `o<over>t<ties>f<flips>m<movers>` with the existing calls (`BuildPlanarChannels`, `FlipPlanarTriangles`, `ResolvePlanarSites`, `PlanarChannelOver`): the v2 variant stores only the tag, not channels, resolved sites or `over`. Slot solve is v1's as-is.
Mapping (file-local): every Line track's slot change between consecutive intervals of its channel, and every site link step (put on the link's `to` line, stretch before its first event, nearest its start). Into a crossing (pre/mid -> x): in the earlier interval's pieces, the insert nearest the crossing; out of a crossing (x -> mid/post): in the later interval's pieces, nearest the crossing; a channel without crossing (pre -> post): the whole line, nearest its end node (start when it ends at a port). Direction: one insert per change whose heading change has the sign of the change; a taken insert is reused only if no other of that direction is in range (0 times). Lock: on = reference 1, all other inserts 0 (`curve_flex_from`, not free). Stage A defaults, 15 s; T2/T3 `PLANAR_STAGEA_COORD=128`.
Sign check: heading is clockwise from north, so heading +1 (d = +1) is a right turn; slots run left to right across travel. Hand check: EF2 m8 goes heading 3 -> 4 (SE to S), clockwise, d = +1 = step to the right. Independent check: over all 12 (T2) and 24 (T3) adjacent line pairs of the channels, the face map's `Side(later, earlier)` is +1 (T1 has one line per channel: 0 pairs).
