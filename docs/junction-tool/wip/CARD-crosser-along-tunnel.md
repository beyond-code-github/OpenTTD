# CARD: a surface line running along a tunnel's line, above it (from V's 197, domain-41)

**Context.** V crosses a tunnel with an S-bend whose straight middle runs directly over the tunnel, along its line: the crosser overlaps its separator for a stretch instead of crossing it at 90 or 45 degrees. L40 does this over L57's tunnel, L89 over L74's. The game allows it (V's save; the domain accepts). Our rules only cover crossers at an angle: D376 (crossers parallel to each other at a span, one angle per span) and D381/D428 keep-apart, so the judge refuses V's 197 at 13 rows (10 keep-apart, 2 deck, 1 port order) for these two places. Triage: wip/probes/domain/triage-197-judge.md §3.

**Options.**
- A. Keep crossings at an angle only (today). V's two places are not reproducible; everything else unchanged.
- B. Allow a crosser to run along a tunnel's middle (heading equal to the separator's, mod 4, over middle tiles only): Shape gets a crossing angle 0 for tunnels (not bridges: a deck's surface is the bridge), Slots exempts the crosser/separator pair over the tunnel's middles from keep-apart and orders the crossing along the run. More compact where a line must jog across a tunnel group; new geometry for Shape and Slots.
- C. B behind a flag as a probe: a domain-suite configuration first (a crosser running along a tunnel's middle), then the rule in the drawing program, measured on 197 (the 13 rows) and T2.

**Recommendation.** C (corpus authority: V builds it; reversible; the suite pins the behaviour before any implementation).

**Prior art checked.** D376, D381, D390, D428, D436; V's save (domain accepts).

**Reversible.** Yes.
